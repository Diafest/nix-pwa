# Nix — PWA-версия

**Версия 2.0** — версия для iPhone.

Задачи с дедлайнами, приоритетами, категориями, повторами, подзадачами и уровнем энергии.
Несколько категорий у задачи, проекты, повтор по выбранным дням недели.
Три вида отображения — список, плитки и доска с настраиваемой осью группировки.
Фокус-таймер, календарь с расписанием дня, статистика с картой активности,
импорт и экспорт JSON.

**Собрано под iPhone.** На Android есть нативное приложение с настоящими
системными будильниками и виджетом — PWA там не нужна, поэтому вёрстка,
жесты и подсказки заточены под Safari и режим «на экран Домой».
Открыть в браузере на компьютере можно, но это не основной сценарий.

Устанавливается на домашний экран, работает офлайн, данные хранятся локально.

---

## Главное ограничение — прочитайте до установки

**Напоминания и фокус-таймер работают только пока приложение открыто или свёрнуто
во вкладку.** Это ограничение самих браузеров: API для запланированных локальных
уведомлений в вебе не существует.

| Ситуация | Напоминание придёт | Таймер тикает |
|---|---|---|
| Приложение открыто | Да | Да |
| Свёрнуто, вкладка жива | Обычно да | Обычно да |
| Полностью закрыто | Нет | Нет, прогресс теряется |
| Телефон перезагружен | Нет | Нет |

При попытке закрыть вкладку во время активной сессии фокуса браузер спросит
подтверждение — чтобы прогресс не пропал молча.

Если напоминания критичны, используйте Android-версию: там настоящие системные будильники.

**Уведомления** работают только если приложение добавлено на домашний экран
(не из вкладки Safari) и только с iOS 16.4+. Приложение само подсказывает,
как это сделать, и предупреждает, если открыто в Chrome — там пункта
«На экран "Домой"» нет.

**Голосовой ввод** Safari на iOS не поддерживает, поэтому кнопка микрофона
не показывается. Вибрации при перетаскивании на iPhone тоже нет — `navigator.vibrate`
в Safari не реализован.

## Как запустить

### Локально, чтобы посмотреть

```bash
cd nix-pwa
python3 -m http.server 8000
```

Откройте `http://localhost:8000`.

Двойным кликом по `index.html` тоже откроется, но service worker и офлайн-режим
по `file://` браузеры блокируют.

### Разместить в интернете

PWA требует **HTTPS**. Бесплатные варианты:

**GitHub Pages** — залить содержимое папки в репозиторий,
`Settings` → `Pages` → ветка `main`, папка `/ (root)`.

**Netlify** — перетащить папку в область «deploy manually», ссылка выдаётся сразу.

**Vercel** — залить как статический проект.

> Из России эти сервисы открываются с перебоями. GitHub Pages стабильнее;
> при проблемах — один раз залить через VPN, дальше сайт работает по прямой ссылке.

## Установка на телефон

**iPhone / iPad:** открыть **обязательно в Safari** → «Поделиться» →
«На экран "Домой"». Chrome на iOS устанавливать PWA не умеет.

**Android:** открыть в Chrome → баннер «Установить приложение» либо меню (⋮) →
«Установить приложение».

## Как пользоваться

### Задачи

Кнопка «+» открывает быстрый лист: название и срок. Остальное — за кнопкой
**«Ещё детали»**: приоритет, энергия, категория, повтор, подзадачи, напоминание.

**Срок словами** прямо в названии: «Позвонить маме завтра в 18:00»,
«Оплатить счёт через 2 часа», «Сдать отчёт в пятницу», «Записаться 15 марта».
Появится подсказка «Поставить срок» — нажмите, и дата подставится.

**Голосовой ввод** — иконка микрофона в поле названия. Работает через Web Speech API;
там, где браузер его не поддерживает (Safari на iOS), кнопка не показывается.
Распознанный текст попадает в поле и его можно поправить.

**Жесты:**

| Действие | Что делает |
|---|---|
| Свайп вправо | Отметить выполненной |
| Свайп влево | Убрать в корзину (хранится 7 дней) |
| Тап по карточке | Открыть редактирование |
| Долгое нажатие | Запустить фокус-таймер |
| Потянуть за ручку справа | Переставить задачу вручную |

Ручка вынесена из зоны нажатия карточки, поэтому долгое нажатие на неё
перетаскивает задачу, а не запускает фокус.

**Цвета на карточке:** полоска слева и свечение — приоритет; красный контур —
просрочка (перебивает приоритет); цветной тег — категория; синяя молния — энергия;
бирюзовая стрелка — повтор; полоска с числами — прогресс подзадач.

### Виды отображения

Кнопка вида в шапке (слева от лупы) перебирает три раскладки по кругу.
Задачи во всех трёх одни и те же — меняется только подача.

| Вид | Что это |
|---|---|
| **Список** | Вертикальные карточки с группировкой по срокам |
| **Плитки** | Те же группы, карточки уложены сеткой; число плиток в ряду зависит от ширины экрана |
| **Доска** | Колонка на каждую категорию, плитки в колонке связаны вертикальной ниточкой |

Вид сохраняется в настройках и переживает перезапуск. Продублирован в
`Настройки → Задачи → Вид задач`.

### Категории

У задачи может быть несколько категорий. Первая выбранная — **основная**:
её показывают там, где место есть только на одну (на узкой плитке остальные
сворачиваются в «+N»). Снять последнюю нельзя.

Фильтр по категории находит задачу, если категория есть среди её тегов.
Разбивка в статистике засчитывает задачу в каждую её категорию.

### Повтор

Кроме готовых режимов есть **«Свои дни»** — 7 переключателей дней недели.
На карточке пишутся сами дни: «Пн, Ср, Пт».

### Доска

Колонки строятся по выбранной оси: **категория, приоритет, силы или проект**
(`Настройки → Задачи → Доска группирует по`). Пустые колонки не показываются.

**Задача с несколькими категориями появляется в каждой своей колонке.**
Колонки листаются вбок; на широком экране их видно несколько сразу.

**Выполненные задачи на доске видны** — они часть цепочки, без них
последовательность внутри колонки рвётся.

**Перетаскивание плитки за ручку меняет только её место в колонке.**
Поле задачи оно не трогает, порядок в списке — тоже. Позиция хранится
в `task.boardPositions` под ключом колонки (`CATEGORY:WORK`, `PRIORITY:HIGH`),
поэтому раскладка по приоритету не сбивает раскладку по категориям.

Сброс — `Настройки → Задачи → Сбросить раскладку доски`. Сбрасывается
**только текущая ось**; другие доски и список не меняются.

### Фокус-таймер

Долгое нажатие на задачу. По умолчанию 25 минут работы и 5 минут перерыва,
интервалы меняются в настройках. Пока идёт сессия, напоминание этой задачи молчит.
Лист можно свернуть — на вкладке «Задачи» появится красная точка.

### Календарь

**День** — вертикальная шкала времени, задачи без времени отдельным списком сверху.
Свайп влево/вправо листает дни.

**Месяц** — сетка с точками по приоритетам. Тап по дню открывает его расписание.

### Статистика

Серия дней подряд, кольцо выполнения за неделю, карта активности за 13 недель
с переключателем «задачи / часы фокуса», разбивки по категориям и затратам сил.
Тап по клетке карты открывает расписание того дня.

### Данные

`Настройки → Экспорт` сохраняет JSON, `Импорт` загружает его обратно.
Дубликаты определяются по точному совпадению названия и срока и пропускаются,
поэтому повторный импорт ничего не задваивает.

Удалённые задачи лежат в корзине 7 дней, потом стираются сами.

---

## Где хранятся данные

В `localStorage` этого браузера — только на этом устройстве, никуда не отправляются.

**Очистка данных сайта удалит все задачи.** Синхронизации между устройствами нет.
Перед сменой телефона или чисткой браузера делайте экспорт.

На iOS есть отдельный нюанс: если не открывать PWA около **7 дней**, система может
очистить её хранилище. Заходите иногда или держите бэкап.

## Структура файлов

```
nix-pwa/
├── index.html              разметка-оболочка
├── app.js                  вся логика: данные, разбор дат, экраны, фокус, статистика,
│                        плитки и доска
├── styles.css              оформление, тёмная и светлая темы
├── sw.js                   service worker: офлайн-кэш
├── manifest.webmanifest    манифест PWA
└── icons/                  иконки для Android, iOS и вкладки
```

Цвета лежат в начале `styles.css`, блок `:root`.
Оформление плиток и доски — блоки `.tile`, `.tile-grid`, `.board` там же.
Блок iOS в конце файла — безопасные зоны, запрет резинового скролла
и 16px в полях ввода (на меньшем размере Safari зумит страницу при фокусе).

При обновлении файлов поднимите `CACHE` в `sw.js` (сейчас `nix-v6`), иначе
установленная PWA продолжит отдавать старую версию из кэша.

| Задачи, категории, приоритеты, энергия | Да | Да |

| Фокус-таймер | Да, работает в фоне | Только пока вкладка жива |

| Повтор по выбранным дням | Да | Да |

## Что добавилось в 2.0

- **Сохранённые виды** — ряд вкладок над списком: фильтр, поиск и раскладка одним тапом. Создать «+», удалить долгим нажатием
- **Метки в тексте** — `#работа !важно ~лёгкая`. Нераспознанная метка остаётся в названии. Разбираются только при создании задачи
- **Правка чипов на карточке** — тап по приоритету или силам перебирает значение без открытия формы

Проекты и шаблоны цепочек в PWA пока только в данных: интерфейс управления
есть в Android-версии. Задачи, созданные там, корректно переносятся через
экспорт/импорт JSON.
